## 📊 Netflix Movies & TV Shows — End-to-End Exploratory Data Analysis

<a href="https://github.com/aayushguptatech-lab/Netflix-Movies-TV-Shows-End-to-End-Exploratory-Data-Analysis-EDA-">
  <img src="https://img.shields.io/badge/View%20Project-Netflix%20EDA-181717?style=for-the-badge&logo=github&logoColor=white" />
</a>

A complete **exploratory data analysis of Netflix's global content library**, covering **8,807 titles released between 1925 and 2021**.

This project goes beyond surface-level charts and explores the **business logic behind Netflix's content library**, identifying structural patterns, content gaps, subscriber-related risks, and potential strategic opportunities.

### 🔍 Analytical Workflow

- 🧹 Data quality assessment
- 🧹 Missing-value treatment
- 🚨 Statistical vs. logical outlier reasoning
- 📊 Univariate analysis
- 🔗 Bivariate analysis
- 🧩 Multivariate analysis
- 📅 Time-series analysis
- 🎬 Director frequency analysis
- 🎭 Cast cross-role analysis
- 📈 Distribution and trend analysis
- 💡 Observation-driven conclusions

### 💡 Key Insights

- 📺 **TV-MA dominates** Netflix's content catalog, highlighting potential implications for emerging-market expansion.
- 📺 **1,793 single-season TV shows** represent a potential hidden subscriber-retention and churn risk.
- 🇮🇳 **India** stands out as one of Netflix's strongest talent/content pools by raw title count.
- ⏱️ **90-minute runtime** represents a major concentration within the movie catalog.
- 📅 **July** shows a notable peak in content additions, suggesting potential programming-calendar opportunities.

### 🛠️ Tools Used

`Python` `Pandas` `NumPy` `Matplotlib` `Seaborn`

### 📂 Dataset

**Netflix Movies and TV Shows — Kaggle**
