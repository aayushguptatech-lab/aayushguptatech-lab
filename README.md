### 📊 Netflix Movies & TV Shows — End-to-End EDA

<a href="https://github.com/aayushguptatech-lab/Netflix-Movies-TV-Shows-End-to-End-Exploratory-Data-Analysis-EDA-">
  <img src="https://img.shields.io/badge/View%20Project-Netflix%20EDA-181717?style=for-the-badge&logo=github" />
</a>

A complete **exploratory data analysis of Netflix's global content library**, covering **8,807 titles released between 1925 and 2021**.

The project goes beyond basic visualization to investigate the **business logic behind Netflix's catalog**, identifying structural patterns, content gaps, and potential strategic opportunities.

The analysis covers:

- 🔍 Data quality assessment
- 📊 Univariate analysis
- 🔗 Bivariate analysis
- 🧩 Multivariate analysis
- 📅 Time-series analysis
- 🎬 Director frequency analysis
- 🎭 Cast cross-role analysis
- 🚨 Statistical vs. logical outlier reasoning
- 🧹 Missing-value treatment

### 💡 Key Insights

- 📺 **TV-MA dominates** the content catalog, highlighting implications for emerging-market expansion.
- 🎞️ **1,793 single-season TV shows** represent a potential hidden subscriber-retention/churn risk.
- 🇮🇳 **India** stands out as one of Netflix's strongest talent/content pools by raw title count.
- ⏱️ **90-minute runtime** represents a major concentration within the movie catalog.
- 📅 **July** shows a notable peak in content additions, suggesting potential programming-calendar opportunities.

**Tools:** Python • Pandas • NumPy • Matplotlib • Seaborn

**Dataset:** Netflix Movies and TV Shows — Kaggle
